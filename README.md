# GitHub Developer Ecosystem Analytics Platform

Analyze GitHub as a social and professional ecosystem — uncover insights about developer behavior, open-source project health, and technology trends.

## Features
- Repository insights (stars, forks, watchers)
- Contributor analytics (commits, PRs, collaboration)
- Issue and commit trends
- Data stored in JSON and SQLite
- Tested with `pytest`

## Tech Stack
Python | GitHub REST API | Pandas | Matplotlib | SQLite
